# WELLB OPENLAB

## 제주 도민이 직접 발견한 문제를, AI와 함께 구조화하고, 현장에서 검증하는 오픈이노베이션 플랫폼

> *"좋은 아이디어는 현장에서 나온다. 그러나 대부분은 구조화되지 못해 실행되지 않는다.  
> WELLB OPENLAB은 그 사이의 간극을 AI와 시민의 협업으로 메운다."*

---

## 1. 왜 지금 WELLB OPENLAB인가

### 1.1 기존 도민 아이디어 수렴 방식의 구조적 한계

제주특별자치도와 JDC는 지역혁신, 관광, 1차산업, 정주환경, 청년 일자리 등 다양한 분야에서 도민과 전문가의 아이디어를 수렴해 왔습니다. 그러나 기존 방식에는 누적적인 구조적 한계가 존재합니다.

| 구조적 문제 | 현상 | 결과 |
|---|---|---|
| **백지 장벽** | 참여자가 아이디어를 '기획서 수준'으로 구조화하는 방법을 모름 | 참여율 저조, 제출 품질 편차 극심 |
| **일회성 운영** | 공모 종료 시 축적된 지식·네트워크 소멸 | 매 회차 제로 베이스 반복, 학습 자산 無 |
| **불투명한 평가** | 심사 기준·과정·피드백이 참여자에게 비공개 | 신뢰 저하, 재참여 의지 감소 |
| **실행 단절** | 선정 후 실증·현장 적용 체계 부재 | '보고서 혁신'으로 종료 |
| **권리 불안** | 제출한 아이디어의 소유권·활용 범위 불명확 | 핵심 아이디어 제출 기피, 방어적 참여 |

### 1.2 WELLB OPENLAB의 접근: AI 증강 오픈이노베이션 루프

WELLB OPENLAB은 위 다섯 가지 한계를 **하나의 통합 플랫폼** 안에서 해결합니다.

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 현장 발견 │ →  │ AI 코칭  │ →  │ 다층 평가 │ →  │ 30일 실증 │ →  │ 검증 자산 │
│          │    │ 구조화    │    │          │    │          │    │          │
│ 도민·현장 │    │ AI Coach │    │ AI+시민  │    │ 현장 파트 │    │ 정책 연계 │
│          │    │          │    │ +전문가  │    │ 너·시설  │    │ 확산 자산 │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
      ↑                                                              │
      └────────────── 실패도 귀중한 학습으로 순환 ──────────────────────┘
```

**핵심 차별점:**
- **AI 코치가 구조화를 도와** 전문가가 아닌 도민(해녀, 농부, 학생, 은퇴자)도 질 높은 제안서를 작성할 수 있습니다.
- **다층 평가(AI 25% + 시민 25% + 전문가 50%)**로 특정 심사위원의 편향을 제거합니다.
- **30일 현장 실증** 설계가 내장되어 '보고서 혁신'에서 벗어납니다.
- **제출된 버전은 불변(immutable)**이며 평가 과정 전체가 플랫폼에 기록됩니다.

## 2. 플랫폼에서 실제로 일어나는 일: 시연 사례

> 아래 사례들은 WELLB OPENLAB에 실제 구축된 데모 데이터 기반의 시나리오입니다.  
> JDC 관계자님께서 플랫폼에 직접 접속하여 전 과정을 확인하실 수 있습니다.

### 사례 ① — 70대 해녀의 아이디어가 실증 프로젝트로

**참여자**: 노해녀 (현직 해녀, 70대)  
**챌린지**: 「관광 경험의 빈 곳 채우기」 (7월)  
**아이디어**: *해녀 채취 수산물 AI 원산지 인증 & 직거래*

노해녀 님은 "물질을 하며 잡은 것인데, 육지에서는 누가 잡았는지 어디서 잡았는지 모른다"는 문제 의식에서 출발했습니다. AI 코치는 이 문제 인식을 **9개 섹션의 아이디어 패스포트** 형태로 구조화하는 것을 도왔습니다. 해녀 님은 스마트폰 음성 입력만으로 패스포트를 완성했습니다.

제출 후 AI 평가(85점)와 전문가 평가(90점)를 거쳐 **PILOT_READY** 단계에 도달했습니다.

> **시사점**: 기존 공모전이었다면 70대 해녀가 '기획서'를 작성하는 것은 불가능에 가까웠습니다.  
> AI 코칭이 **참여의 문턱을 제거**하고, 결과물의 품질은 전문가 수준으로 끌어올린 사례입니다.

---

### 사례 ② — 보건소 간호사의 아이디어가 실증까지 완료

**참여자**: 배간호 (제주 시골 보건소 간호사)  
**챌린지**: 「함께 사는 돌봄과 생활」 (6월)  
**아이디어**: *제주 시골 마을 AI 복약 알리미 & 건강 챗봇*

배간호 님은 매일 수십 명의 어르신에게 전화로 복약 확인을 하며, "사람이 이걸 매일 하기엔 한계가 있다"는 절실함에서 아이디어를 시작했습니다.

| 평가 단계 | 점수 | 핵심 피드백 |
|---|---|---|
| **AI 평가** | 88/100 | "보건소와의 연계 가능성이 매우 현실적입니다" |
| **전문가 평가** | 92/100 | "고령자 복약 불이행 리스크를 크게 낮출 수 있습니다" |

**실증 결과**: 구좌읍 보건소와 연계하여 65세 이상 어르신 50명 대상으로 30일간 카카오톡 기반 복약 알림 시범운영을 완료하여 **VALIDATED** 상태에 도달했습니다.

> **시사점**: 현장 실무자의 체감 문제가 → AI 구조화 → 다층 평가 → 현장 실증까지 하나의 파이프라인 안에서 진행된 대표 사례입니다. JDC가 실증 파트너로 참여하면 이러한 파일럿의 규모와 속도를 크게 확대할 수 있습니다.

---

### 사례 ③ — 청년 창업자와 중학교 교사의 교차 참여

**참여자**: 송청년 (이주 청년 창업자), 권선생 (중학교 교사, 환경교육 담당)  
**챌린지**: 「이동과 안전」 (8월)

송청년 님은 *제주 청년 창업 AI 멘토링 매칭 시스템*을, 권선생 님은 *제주 해양 쓰레기 AI 분류 & 업사이클 자원화*를 제출했습니다. 두 아이디어는 서로 다른 트랙에 속했지만, **시민 비교(Pairwise) 평가** 과정에서 참여자들 사이에 자연스러운 교류가 발생했습니다.

권선생 님은 이전 챌린지 「함께 사는 돌봄과 생활」에도 참여한 이력이 있어, 한 시즌에 걸쳐 **아이디어를 발전시키고 반복 참여하는 학습 루프**가 형성된 사례입니다.

> **시사점**: 일회성 공모전에서는 만날 일이 없는 '이주 청년 창업자'와 '중학교 교사'가 같은 챌린지 안에서 만나 서로의 아이디어에 피드백을 주고받습니다. 이것이 **도민 참여 기반 AX(AI Transformation)**의 본질입니다.

---

### 사례 ④ — 소농의 AI 직거래 플랫폼이 현장 실증 진행 중

**참여자**: 이혁신 (청년 창업가)  
**챌린지**: 「이동과 안전」 (8월)  
**아이디어**: *제주 소농 AI 수요예측 공동 직거래 플랫폼*

구좌읍 감귤·당근 소농 5가구를 대상으로, AI 수요예측 기반 사전예약 직거래 시스템을 1주일간 시범 운영 중(**IN_PILOT**)입니다. 목표: 감귤 100박스를 3일 내 소진하고, 농가 수수료 부담을 40%에서 15%로 절감하는 것.

> **시사점**: JDC의 지역산업 지원 미션과 직접 연결되는 사례입니다. 이러한 실증 데이터가 누적되면 JDC의 **지역산업 지원 정책 수립에 근거 자료**로 활용할 수 있습니다.

---

### 사례 ⑤ — 은퇴 교사부터 대학생까지, 22명의 도민 참여자 프로필

현재 플랫폼에는 아래와 같은 **다양한 배경의 22명** 도민 참여자가 활동하고 있습니다.

| 참여자 | 배경 | 참여 챌린지 | 제출 아이디어 |
|---|---|---|---|
| 오시니어 | 은퇴 교사, 원도심 거주 | 돌봄·생활 / 소상공인 | 독거 어르신 AI 안심 모니터링, 전통 시장 AI 안내 |
| 문농부 | 중산간 감귤 농가 | 관광 경험 | 감귤밭 스마트 관수·시비 AI 어시스턴트 |
| 양카페 | 제주 카페 소상공인 | 소상공인 AX | 소상공인 AI 메뉴판 & 다국어 추천, 빵집 AI 재고 예측 |
| 하공무 | 제주시청 주민자치과 | 돌봄·생활 / 생활혁신 | 워킹맘 긴급 돌봄 매칭 플랫폼 |
| 조학생 | 제주대 컴공과 | 생활혁신 | 이주민 생활정보 AI 원스톱 안내 |
| 신디자 | 프리랜서 UX 디자이너 | 관광 / 소상공인 | 올레길 AI 맞춤추천, 로컬 크리에이터 AI 스튜디오 |

> **핵심 수치**: 22명의 참여자가 6개 챌린지에 걸쳐 **25개 아이디어**를 제출했습니다.  
> 이 중 5건이 PILOT_READY 이상으로 진행되었고, 2건의 현장 실증이 완료되었습니다.

## 3. 플랫폼 핵심 구조

### 3.1 챌린지 시리즈 & 월간 챌린지

**연간 12개월 제주 특화 테마 로드맵 (운영 실적 포함)**

| 월 | 테마 | 핵심 키워드 | 운영 현황 |
|---|---|---|---|
| 5월 | **동네 가게, AI로 발견되다** | 소상공인, GEO 최적화 | ✅ 완료 · 아이디어 4건 |
| 6월 | **함께 사는 돌봄과 생활** | 포용적 생활, 돌봄 | ✅ 완료 · 실증 2건 |
| 7월 | **관광 경험의 빈 곳 채우기** | 관광 품질, 경험 혁신 | ✅ 완료 · 검증 1건 |
| 8월 | **이동과 안전** | 모빌리티, 공공 안전 | 🟢 진행 중 · 참여 8명 |
| 9월 | **농수산과 로컬 푸드 혁신** | 1차산업, 푸드테크 | 🟢 진행 중 |
| 10월 | **청년의 기회와 새로운 일** | 청년 정주, 일자리 혁신 | 📋 예정 |
| 11월 | 공공 지식과 시민 서비스 | 행정 혁신, 시민 참여 | 📋 예정 |
| 12월 | 제주에서 세계로 | 글로벌 확장, 수출 | 📋 예정 |

> 스폰서는 월간 테마 제안 및 현장 챌린지 연계에 참여할 수 있습니다.

### 3.2 아이디어 패스포트 (Idea Passport)

참여자의 아이디어를 **9개 표준 섹션**으로 구조화합니다. AI 코치가 각 섹션 작성을 안내하며, **사용자 확인 없이 원본을 변경하지 않습니다**.

```
┌─────────────────────────────────────────────────────────┐
│                    IDEA PASSPORT                        │
├─────────────────────────────────────────────────────────┤
│  1. 정체성    제목 · 한줄 요약 · 트랙 · 카테고리         │
│  2. 문제      대상 · 맥락 · 관찰된 문제 · 현재 대안      │
│  3. 사람·맥락  주요 사용자 · 이해관계자 · 운영 환경       │
│  4. 솔루션    핵심 해결책 · 사용자 흐름 · 기대 가치       │
│  5. 실현성    필요 자원 · 비용 · 제약 · 리스크            │
│  6. 임팩트    직접 수혜자 · 기대 변화 · 측정 지표         │
│  7. 실험      핵심 가정 · 최소 프로토타입 · 30일 검증     │
│  8. 근거      사실/경험/가정 구분 · 출처 명시             │
│  9. 출처 추적  사용자원본/AI제안/외부출처 자동 기록        │
└─────────────────────────────────────────────────────────┘
```

### 3.3 다층 평가 시스템

```
                    ┌──────────────────────┐
                    │   Selection Gate     │
                    │  (정성적 최종 검토)   │
                    │   0% 수치 가중치     │
                    └──────────┬───────────┘
                               │
          ┌────────────────────┼────────────────────┐
          │                    │                    │
   ┌──────┴──────┐    ┌───────┴───────┐    ┌───────┴───────┐
   │  AI 평가    │    │  시민 비교    │    │  전문가 평가  │
   │   25%       │    │   25%         │    │   50%         │
   │ 공개 루브릭 │    │ 익명 A/B     │    │ 현장 실현성   │
   │ 즉시 피드백 │    │ 페어와이즈   │    │ 리스크 분석   │
   └─────────────┘    └───────────────┘    └───────────────┘
```

**핵심 원칙:**
- AI 점수만으로 자동 탈락시키지 않습니다.
- 평가는 제출된 불변 스냅샷(Submitted Version) 기준입니다.
- Selection Gate는 숨겨진 보너스, 스폰서 단독 오버라이드, 배경 기반 선정을 금지합니다.

## 4. JDC 참여 시 제주 지역사회 공헌 효과

```
┌─────────────────────────────────────────────────────────────────────┐
│                  JDC 앵커 스폰서 참여 구조                          │
│                                                                     │
│  JDC의 강점              WELLB OPENLAB의 강점                       │
│  ─────────              ───────────────────                        │
│  · 제주 현장 인프라       · AI 증강 아이디어 구조화                  │
│  · 실증 시설·파트너       · 다층 평가 시스템                         │
│  · 지역산업 네트워크      · 불변 기록·투명 거버넌스                   │
│  · 정책 연계 통로         · 시민 참여 플랫폼                         │
│  · 대규모 홍보 채널       · 30일 실증 설계 프레임                    │
│                                                                     │
│              ↓  결합 시 기대 효과  ↓                                │
│                                                                     │
│  ① 도민 참여 저변 확대 (백지 장벽 제거)                             │

│  ⑤ 중앙정부 대상 선진 지역혁신 거버넌스 모델 제시                    │
```

### 4.2 도민 참여 기반 AX — JDC가 이끄는 변화

WELLB OPENLAB에서의 AX(AI Transformation)는 **기업이 AI를 도입하는 것**이 아니라, **도민이 AI와 함께 지역 문제를 푸는 것**입니다. JDC가 앵커 스폰서로 참여하면 다음과 같은 구체적 변화가 발생합니다.

#### (1) "아이디어를 낼 수 없었던 사람"이 참여합니다

| 기존 방식 | WELLB OPENLAB 방식 |
|---|---|
| A4 기획서 작성 필요 → 전문가만 참여 | AI 코치가 대화형으로 구조화 → 해녀, 농부, 학생도 참여 |
| 한국어 글쓰기 능력 필수 | 음성 입력 + AI 정리 가능 |
| 1회 제출, 피드백 없음 | 실시간 AI 피드백 → 재수정 → 재제출 |

**시연 근거**: 현재 플랫폼의 22명 참여자 중 70대 해녀(노해녀), 은퇴 교사(오시니어), 중산간 감귤 농가(문농부) 등 **기존 공모전에서는 참여 자체가 어려웠을 도민**이 실제로 아이디어를 제출하고 평가까지 받았습니다.

#### (2) "보고서로 끝나는 혁신"이 현장 검증으로 이어집니다

| 기존 방식 | WELLB OPENLAB 방식 |
|---|---|
| 선정 → 시상 → 보고서 제출 | 선정 → 30일 현장 실증 → 검증 결과 축적 |
| 실행 책임 불명확 | 실증 파트너·시설·일정이 패스포트에 미리 설계 |

**시연 근거**: 배간호 님의 'AI 복약 알리미'는 구좌읍 보건소와 연계하여 실제로 30일간 시범운영을 완료(VALIDATED)했습니다.

#### (3) 실패도 자산이 됩니다

NOT_VALIDATED 사례도 **왜 실패했는지, 어떤 가정이 틀렸는지**가 플랫폼에 기록됩니다. 이 데이터는 다음 챌린지의 참여자에게 학습 자료로 제공됩니다. 기존 공모전에서는 실패 사례가 아예 기록되지 않습니다.
